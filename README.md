# Kyzam

Tento repozitář slouží pro web projektu Kyzam.

## Co zde bude
- HTML, CSS a JavaScript soubory webu
- statická webová stránka nebo jednoduchý projekt

## Jak nahrát web
1. Nahraj všechny soubory webu do kořene repozitáře.
2. Ujisti se, že hlavní soubor je `index.html`.
3. Pokud je web statický, můžeš ho nasadit na GitHub Pages nebo na externí hosting.

## Doporučení
- Všechny soubory webu ukládej do kořene repozitáře nebo do podsložky, kterou budeš správně odkazovat.
- Pokud používáš obrázky nebo CSS, zkontroluj, že cesty k souborům jsou správné.
